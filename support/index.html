Help with Rebacked for macOS.

Contact

Email: rebackedsupport@proton.me

System Requirements

Rebacked requires macOS 14 or later.

Supported Formats

  • EPUB
  • PDF
  • MOBI
  • AZW3

Does Rebacked modify my original books?

Rebacked is designed to preserve your original source files. EPUB metadata and cover changes are written to a new exported copy rather than silently replacing the source book.

Why can't Rebacked modify MOBI or AZW3 files?

Rebacked currently manages metadata for these formats inside your library but exports the original source file unchanged.

What happens if I move a source book?

If Rebacked can no longer access a source file, use Locate Source to reconnect the existing library entry to the moved file.

Kindle

Rebacked can prepare supported EPUB and PDF books for manual Kindle workflows. Amazon's Send to Kindle service remains separate from Rebacked.

Kobo

Rebacked can prepare and copy supported EPUB and PDF files for Kobo devices when the workflow is available.

DRM

Rebacked does not remove or circumvent DRM.
